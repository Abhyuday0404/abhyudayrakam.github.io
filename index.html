Financial planning for India Jul–Oct 2026 · Solo project Agentic AI View on GitHub

MedSwap

Drug Substitution RAG Feb 2025–Jun 2026 · Solo project Gemini 1.5 Flash, Gemini text-embedding-004, DataStax Astra DB, FastAPI, React, Vite, Tailwind CSS

Built a RAG-based medicine substitution assistant for Indian patients to find medicines with the same active composition when a prescribed drug is unavailable locally, using official sources including Jan Aushadhi, NFI, and the WHO Essential Medicines List.

Used Gemini for structured extraction and embeddings, Astra DB for vector storage, and a FastAPI backend with a React interface. Designed the assistant to cite sources and return “not found” rather than guess.
